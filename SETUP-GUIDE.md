# 🚀 RADICI DI PUGLIA — Complete Setup Guide
### From zero to live website in under 30 minutes

---

## STEP 1 — Download Your Project Files

1. Download the `radici-di-puglia.zip` file I provided
2. Unzip it on your computer — you'll see a folder called `radici-di-puglia`
3. Open it — inside you'll find `index.html`, and folders `css/`, `js/`, `images/`

---

## STEP 2 — Create a GitHub Account (free, 3 minutes)

GitHub is where your website code lives. Think of it as Google Drive, but for code.

1. Go to **github.com**
2. Click **"Sign up"**
3. Enter your email, choose a username (e.g. `radicidipuglia`) and a password
4. Verify your email

---

## STEP 3 — Create Your GitHub Repository

A "repository" is just a folder for your project on GitHub.

1. Once logged in, click the **"+"** icon (top right) → **"New repository"**
2. Repository name: `radici-di-puglia`
3. Set it to **Public**
4. Click **"Create repository"**
5. On the next page, click **"uploading an existing file"**
6. Drag all your project files AND folders into the upload box
   ⚠️ Important: upload the files INSIDE the folder, not the folder itself
7. At the bottom, click **"Commit changes"**

✅ Your code is now saved on GitHub!

---

## STEP 4 — Create a Netlify Account & Deploy (free, 2 minutes)

Netlify turns your GitHub code into a live website with a real URL.

1. Go to **netlify.com**
2. Click **"Sign up"** → choose **"Sign up with GitHub"** (easiest!)
3. Authorise Netlify to access your GitHub
4. Click **"Add new site"** → **"Import an existing project"**
5. Click **"GitHub"**
6. Select your `radici-di-puglia` repository
7. Leave all settings as default
8. Click **"Deploy site"**

⏳ Wait about 30 seconds...

🎉 **Your site is now LIVE!**

You'll get a URL like: `https://radiant-sunshine-a1b2c3.netlify.app`

Share this link with anyone in the world — it works immediately!

---

## STEP 5 — Change the Temporary URL (optional but recommended)

The auto-generated URL is ugly. Let's make it nicer — for free:

1. In Netlify, go to **"Site configuration"** → **"Site details"**
2. Click **"Change site name"**
3. Type: `radicidipuglia`
4. Click Save

Your site will now be at: **`https://radicidipuglia.netlify.app`** ✅

---

## STEP 6 — Get a Real Domain Name (optional, ~€12/year)

A proper domain like `radicidipuglia.com` looks professional.

**Where to buy it:**
- **Namecheap.com** → cheapest, easy to use (~€10-12/year)
- **Cloudflare.com** → good option, no markup on price

**How to connect it to Netlify:**
1. Buy the domain on Namecheap
2. In Netlify → **"Domain management"** → **"Add a domain"**
3. Type your domain name
4. Netlify will show you DNS settings to copy
5. Go back to Namecheap → **"Manage DNS"** → paste the settings
6. Wait 10-30 minutes → done! ✅

---

## STEP 7 — Update Your Email in the Booking Button

The booking button currently says `info@radicidipuglia.com`.
Replace it with your real email:

1. Open the `index.html` file in any text editor (even Notepad/TextEdit)
2. Press **Ctrl+F** (or Cmd+F on Mac) and search for: `info@radicidipuglia.com`
3. Replace it with your real email address
4. Save the file
5. Go to GitHub → open `index.html` → click the pencil icon (Edit) → paste the updated content → Commit
6. Netlify will automatically redeploy in ~30 seconds

## STEP 8 — How to Update the Website in the Future

Every time you want to change something:

**Easy way (GitHub web):**
1. Go to github.com → your repository
2. Click on the file you want to edit (e.g. `index.html`)
3. Click the pencil icon ✏️
4. Make your changes
5. Click **"Commit changes"**
6. Netlify automatically rebuilds your site in ~30 seconds!
